scene.json 字段速查

顶层：schema name prefix meta.viewbox layout parts poses clips sequence

poses[*].parts 存各部件控制点； clips[*].steps 为设备端离散 step（非时间轴）。

流程：打开 / 拖入 JSON → 识别并整理（可选）→ 编译并仿真 → 导出 .inc。

场景信息

rig 导入时等比（fit）缩放到此尺寸并居中；留空沿用 Lottie 原始尺寸。圆屏设置会写入场景，并同步影响预览裁剪。

这里的修改会立即写回当前 scene.json；文件落盘请用顶栏「保存场景」。

部件列表

单击 focus / 再点取消；focus 后双击可弹框放大查看 / 编辑控制点。右侧眼睛按钮控制 hidden，上下箭头调整层级。

选中部件属性

固定颜色会自动绑定到该部件；底层导出时会自动整理成内部调色板。 opacity=0 兼容导出为全不透明（255）。

选中部件后，修改属性会立即生效。
